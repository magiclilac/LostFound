# Campus Lost & Found Management System

A simple Django-based web application for managing lost and found items on a college campus.

### Features
- Admin Login
- Add, View, Edit & Delete Reports
- Lost & Found Management
- Report Status Management
- Admin Dashboard

### Technologies
Python, Django, HTML, CSS, SQLite

### Run the Project

```bash
cd CampusLostFound
python -m venv venv
venv\Scripts\activate
pip install django
